# Week 6 - Baseline Evaluation

## Objective
To create a golden question set with expected answers and sources, and perform the first baseline evaluation using a local LLM.

## Files
- golden_set.json - Contains 5 questions, expected answers and sources.
- main.py - Runs the questions using the Ollama model.
- baseline_results.csv - Stores generated answers and response times.
- requirements.txt - Lists project requirements.

## Tools Used
- Python
- Ollama
- Llama 3.2

## Execution
1. Installed and verified the Ollama Llama 3.2 model.
2. Created a golden question set with 5 questions.
3. Executed main.py to generate answers.
4. Saved the baseline results in a CSV file.

## Results
- Total questions: 5
- Successful responses: 5
- Failed responses: 0
- Baseline evaluation completed successfully.

## Response Time

| Question | Time (seconds) |
|---|---:|
| Artificial Intelligence | 52.53 |

| Natural Language Processing | 63.91 |

## Conclusion
The first baseline evaluation was completed successfully using the Ollama Llama 3.2 model. All 5 questions generated responses, and the results were saved in baseline_results.csv.
